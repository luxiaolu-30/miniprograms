## Why

根据艾宾浩斯遗忘曲线，人类在学习新知识后，如果不复习，1天后仅保留约33%，30天后仅保留约21%。间隔重复（Spaced Repetition）是公认最高效的记忆方法，但大多数人没有工具来系统执行复习计划。现有记忆类 App（如 Anki）功能复杂、学习成本高，且多为独立 App 而非微信生态内触手可及的小程序。需要一个轻量的微信工具，让用户录入知识点后自动计算复习计划，每天准时提醒复习。

## What Changes

- 在 `D:\files\miniprograms\` 下新建 `ebbinghaus-miniprogram/` 文件夹，作为独立微信小程序项目
- 用户可录入知识点（标题 + 内容 + 可选图片 + 可选分类），支持补录（选择学习日期）
- 系统根据艾宾浩斯曲线自动生成 6 次复习计划（+1/+3/+7/+14/+29/+59 天）
- 日历月视图展示每天的待复习数量，点击日期查看当天复习列表
- 今日页面展示当天待复习知识点，支持标记完成
- 每天早上 8 点通过微信订阅消息推送今日复习提醒
- 图片纯本地存储（拍照/相册选择 + 压缩），不上传云端
- 云数据库仅镜像复习计划骨架（用户_openid + 知识点ID + 计划日期 + 状态），用于定时通知查询
- 分类管理：可选分类，支持 CRUD
- 学习统计：已掌握/学习中/累计学习数量

## Capabilities

### New Capabilities
- `knowledge-input`: 知识点录入/编辑，支持标题、内容、图片（拍照/相册/本地存储/压缩）、分类选择、学习日期选择（可补录）
- `review-scheduler`: 基于艾宾浩斯曲线的复习计划生成与管理，6 次间隔（1/3/7/14/29/59 天），状态流转（pending → done），逾期堆积显示
- `calendar-view`: 日历月视图，标记每天待复习数量，点击展开当天复习列表
- `today-review`: 今日复习页面，展示当天所有待复习知识点，支持标记完成
- `daily-notification`: 每日 8 点微信订阅消息推送，云函数定时触发器查询云数据库发送通知
- `cloud-sync`: 复习计划骨架同步到云数据库（最小化同步，不含内容和图片）
- `category-management`: 分类 CRUD，可选关联
- `learning-stats`: 学习统计概览

### Modified Capabilities
（无 — 全新项目）

## Impact

- **新增代码**: 独立微信小程序项目 `ebbinghaus-miniprogram/`（pages、components、utils、云函数）
- **存储**: 本地 wx.storage（知识点元数据 + 复习计划）+ 本地文件系统（图片）+ 云数据库（复习计划骨架镜像）
- **云开发**: 需要开通微信云开发（定时触发器 + 订阅消息 + 云数据库）
- **依赖**: 原生小程序框架 + 云开发 SDK（无第三方 UI 库）
- **平台**: iOS + Android 微信小程序
- **数据迁移**: 纯本地数据，预留导出接口
