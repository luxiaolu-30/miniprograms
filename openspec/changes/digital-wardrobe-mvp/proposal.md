## Why

随着个人物品（衣物、书籍、数码藏品、纪念品等）逐渐积累，人们很难全面了解自己拥有什么，导致重复购买、物品闲置遗忘。现有方案要么是纯相册（无结构化属性），要么是单一品类应用（只管衣物或只管书籍）。需要一个统一的收纳整理工具，让用户以拍照+文字方式录入物品，自定义品类和属性，在一览视图中管理所有个人物品，并跟踪物品的生命周期。

## What Changes

- 新增微信小程序"电子衣橱"，纯本地存储，无需后端
- 支持拍照多图录入 + 文字属性填写
- 用户可自定义品类及品类属性模板（如"黑胶唱片"有艺人、年份、厂牌字段）
- 预设品类：衣物、书籍、数码藏品、纪念品
- 物品状态管理：在用 → 闲置 → 已处理（捐赠/转卖/丢弃/借出），支持归档和恢复
- 浏览视图：网格/列表切换、按品类/标签筛选、全文搜索
- 数据导出为 JSON 文件，支持分享保存

## Capabilities

### New Capabilities
- `local-storage`: 纯本地数据存储层，管理物品元数据（wx.storage）和图片文件（本地文件系统），含图片压缩
- `category-management`: 品类 CRUD + 字段模板设计，预设品类与用户自定义品类
- `item-management`: 物品 CRUD，支持多图、动态属性表单、标签、备注
- `image-capture`: 多图拍照/相册选择、压缩、本地文件存储与读取
- `item-disposal`: 物品状态流转（在用/闲置/已处理），处理信息记录，归档与恢复
- `browse-search`: 首页浏览（网格/列表）、品类筛选、标签筛选、搜索、统计概览

### Modified Capabilities
（无 — 全新项目，无既有能力变更）

## Impact

- **新增代码**: 微信小程序完整项目（pages、components、utils、storage 层）
- **存储**: 纯本地，使用 wx.storage（上限 ~10MB 元数据）+ 本地文件系统（图片）
- **依赖**: 原生小程序框架（无第三方后端），可选 Vant Weapp UI 组件库
- **平台**: iOS + Android 微信小程序
- **数据迁移**: 纯本地无迁移，预留 JSON 导出接口供未来云同步使用
